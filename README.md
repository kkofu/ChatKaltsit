## 
```
python -m venv .venv
.venv/Scripts/activate
pip install -r requirements.txt
```

- Run web app: `python run_app.py`
- Run CLI: `python chat_cli.py`
- Build portable server: `python build_mini.py`
- Re-extract dialogue from [ArknightsStoryJson](https://github.com/050644zf/ArknightsStoryJson): `python extract_kaltsit_dialogues.py`
- Re-generate character profile: `python analyze_kaltsit_language.py`
